# Changelog

## 1.1.0

- **Welcome guide:** a short illustrated tour on first launch, explaining what FLeeker does and how
  to use it (reopen it anytime with the **?** button)
- **New icon:** a magnifying glass over the FL Studio colors
- **macOS installer:** a `.dmg` with the classic window, just drag FLeeker onto Applications
- New languages: Chinese (Simplified), German, Spanish and French, alongside English and Italian
- Language menu (🌐) in the top bar; the app starts in English and remembers your choice
- Chinese, Japanese and Korean sample names are displayed correctly (uses the system font)
- The favorites file is found automatically even when the FL Studio user data folder was moved
  to another drive

## 1.0.0

First public release.

- Relinks FL Studio browser favorites (Starred) whose samples were moved
- Finds samples that were moved **and** renamed, by content
- Tells apart different samples that share the same file name
- Removes duplicate entries and favorites already listed under another name
- Preview mode, automatic backups with one-click restore, refuses to write while FL Studio is running
- English and Italian interface, dark and light themes, resizable panels
- Windows and macOS (Apple Silicon and Intel) builds
